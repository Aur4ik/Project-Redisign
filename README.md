# AlaAuto
Учебный Frontend MVP автосалона. React + Vite, обычный CSS, без серверной части.

## Запуск
Установите Node.js 20.19+ или 22.12+ с npm. В терминале в папке проекта выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для сборки: `npm run build`. Для просмотра сборки: `npm run preview`.

## Возможности
- Каталог из 6 демонстрационных автомобилей.
- Поиск, фильтрация и сортировка.
- Подробная карточка автомобиля.
- Избранное с сохранением в localStorage.
- Форма тест-драйва, проверка данных, сохранение и удаление заявок.
- Адаптивная вёрстка; иллюстрации SVG без зависимости от сторонних фотохостингов.

Демонстрационная заявка не отправляется в автосалон. Записи хранятся только в браузере. Внешний Google Fonts необязателен: при отсутствии сети используется Arial.

## Структура
- src/main.jsx — React-компоненты, экраны и обработка действий.
- src/cars.js — данные демонстрационного каталога.
- src/style.css — адаптивное оформление.
- WORKSHEET.md — заполненный рабочий лист.
- STATUS.md — фактическое состояние технических шагов.

## GitHub
Локальный репозиторий и первый коммит подготовлены, если это подтверждено в STATUS.md. Создайте пустой репозиторий AlaAuto в своём аккаунте GitHub (без README и .gitignore), затем выполните в папке проекта:

```sh
git remote add origin https://github.com/YOUR_USERNAME/AlaAuto.git
git push -u origin main
```

Замените YOUR_USERNAME своим логином. Если вы скачали ZIP, в нём нет папки .git. Сначала выполните:

```sh
git init -b main
git add .
git commit -m "Initial commit"
```

После push вставьте ссылку на репозиторий в STATUS.md. Если Git запросит имя и email автора, задайте свои значения через `git config user.name` и `git config user.email`.

## Проверка вручную
1. Установите кузов «Кроссовер» и бюджет до 20 млн: должен остаться Hyundai Tucson.
2. Введите несуществующую модель: должно появиться пустое состояние. Сбросьте фильтры.
3. Сохраните машину сердечком, обновите страницу и откройте «Избранное»: она остаётся в коллекции.
4. Откройте машину и форму тест-драйва. Неправильный телефон не должен сохранять заявку. Прошедшая дата не должна приниматься.
5. Заполните форму тестовыми данными (например, «Тест», +7 700 000 00 00), выберите сегодняшнюю или будущую дату и дайте согласие. Убедитесь, что заявка появляется в «Мои заявки» после перезагрузки.
6. Удалите заявку и проверьте отсутствие после перезагрузки.
7. Проверьте каталог и форму на ширине экрана 375 px и навигацию клавиатурой.
