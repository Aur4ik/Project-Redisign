# Состояние AlaAuto 2.0

Дата: 23 октября 2026 года.

## Реализовано
- React/Vite с React Router, отдельные страницы, контексты авторизации и каталога, обработка загрузки и ошибок.
- Go/Gin REST API, GORM, постоянная база SQLite. Подключение PostgreSQL предусмотрено через DATABASE_URL.
- Регистрация, вход, bcrypt, JWT в HttpOnly-cookie, отзыв сессии при выходе.
- Покупатель и администратор; права проверяются сервером, роль при регистрации не принимается от клиента.
- Каталог, поиск, фильтры, сортировка, подробные карточки.
- Личное избранное в БД.
- Свободные слоты, заявки на тест-драйв, статусы, отмена, проверка времени и уникальность слота.
- Админка: добавление/редактирование/архивирование машин, восстановление через редактор, обработка заявок, пользователи.
- Команда npm start для запуска двух частей; Go также раздаёт готовую сборку из dist.
- Обновлены README, API.md и рабочий лист.

## Проверено автоматически
Успешно выполнены go test ./... -count=1, go build и npm run build.

4 интеграционных теста API включают проверки:
1. Регистрация, повторный email, правильный и неправильный пароль, запрет присвоения admin через JSON, хеширование пароля, HttpOnly-cookie, запрет чужого origin и неверного JWT, отзыв сессии, серверные права.
2. Фильтр каталога, избранное разных пользователей, идемпотентность добавления, создание/редактирование/архивирование машины, валидация цены.
3. Создание и отмена заявки, недоступность чужих заявок, занятый слот, статусы, отказ завершить будущий тест-драйв, некорректные телефон/дата/согласие.
4. Конкурентная запись на один слот: одна успешная заявка и один конфликт; сохранение заявки после закрытия и повторного открытия SQLite.

Автоматические тесты используют временные базы. Рабочие данные не затрагиваются.

## Проверено в браузере на отдельной QA-базе
- Регистрация тестового покупателя и переход в профиль.
- Добавление машины в серверное избранное и сохранение после перезагрузки.
- Карточка машины и загрузка доступного времени.
- Отказ при неверном телефоне и успешная запись с корректными данными.
- Заявка видна в личном списке после перезагрузки; отмена меняет статус.
- Production-сборка открывается через Go, прямая ссылка /cars/1 работает после перезагрузки.

## Ограничения проверки
- PostgreSQL и отдельная мобильная ширина не проверены.
- Панель администратора реализована, её маршруты проверены автоматическими тестами. Проверка админки в браузере требует временно назначить администратора тестовому аккаунту в отдельной QA-базе; автоматический контроль безопасности запросил явное разрешение пользователя. До его получения это назначение не выполнялось.
- Тестовые аккаунты и заявки из QA-базы не копируются в рабочую базу C:\AlaAuto.
- Уведомления, платежи, интеграции настоящего автосалона и сброс пароля не реализованы.
