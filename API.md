# AlaAuto REST API

База URL: http://127.0.0.1:8081/api. В dev-режиме обращайтесь через http://127.0.0.1:5173/api, чтобы использовать cookie того же origin.

Тела изменяющих запросов — JSON с Content-Type: application/json (для DELETE/PUT без данных достаточно {}). Ошибка: {"error":"Понятное сообщение"}. Приватные маршруты требуют HttpOnly-cookie alaauto_session, получаемую при регистрации или входе. В Postman включите cookie jar. Пароль и JWT не возвращаются в JSON.

## Публичные маршруты
| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка сервера и БД |
| POST | /auth/register | Регистрация: name, email, password (8–72 байта) |
| POST | /auth/login | Вход: email, password |
| GET | /cars | Активные автомобили; q, brand, body, maxPrice, sort=low/high/new |
| GET | /cars/:id | Один активный автомобиль |
| GET | /cars/:id/availability?date=YYYY-MM-DD | Свободные слоты UTC+5; уже занятые и прошедшие исключены |

## Авторизованный пользователь
| Метод | Путь | Назначение |
|---|---|---|
| GET | /me | Текущий пользователь |
| POST | /auth/logout | Отзыв текущей сессии |
| GET | /favorites | Массив ID сохранённых машин |
| PUT | /favorites/:id | Добавить машину (идемпотентно) |
| DELETE | /favorites/:id | Убрать машину |
| GET | /bookings | Только свои заявки |
| POST | /bookings | Создать заявку |
| DELETE | /bookings/:id | Отменить свою активную заявку, сохранить историю |

Пример заявки:
```json
{"carId":1,"name":"Тестовый покупатель","phone":"+7 700 000 00 00","date":"2026-11-01","time":"10:00","consent":true}
```
Дата должна быть в будущем и в пределах 90 дней. Часы: 10:00, 11:00, 12:00, 14:00, 15:00, 16:00, 17:00. Одна машина не может быть одновременно забронирована двумя пользователями на один слот.

## Администратор
| Метод | Путь | Назначение |
|---|---|---|
| GET | /admin/cars | Все машины, включая архив |
| POST | /admin/cars | Добавить машину |
| PUT | /admin/cars/:id | Полное обновление машины |
| DELETE | /admin/cars/:id | Архивировать, не удалять историю |
| GET | /admin/bookings | Все заявки с пользователями и автомобилями |
| PATCH | /admin/bookings/:id/status | Изменить статус: {"status":"confirmed"} |
| GET | /admin/users | Пользователи без паролей |

Модель автомобиля: brand, model, year, price (тенге целым числом), mileage, body, fuel, engine, power, drive, color (#RRGGBB), tag, description, image (пустая строка или HTTPS URL), active (bool).

Переходы статусов: pending → confirmed/cancelled; confirmed → completed/cancelled. completed возможен после начала слота. Отменённые и завершённые заявки нельзя подтверждать заново.

Коды: 200/201 — успех; 204 — успех без тела; 400 — неверные данные; 401 — требуется вход; 403 — нет прав/запрещённый origin; 404 — объект не найден или чужая заявка; 409 — дубликат email, занятое время, конфликт статуса; 415 — неверный Content-Type; 429 — лимит авторизации; 500 — ошибка сервера.

Ограничение входа/регистрации: 30 запросов за 10 минут на IP в рамках одного процесса. Для публичной эксплуатации за прокси потребуется настроить trusted proxy и общий лимитер.
